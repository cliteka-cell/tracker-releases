# Tracker is now Voynich

Tracker has a new name, Voynich, and a new home: **https://github.com/cliteka-cell/voynich-releases** (the website is
https://cliteka-cell.github.io/voynich-releases/).

If you use Tracker, it updates itself to Voynich (Settings, About, Check now) and keeps everything you made. You can also
download the newest `Voynich-Setup.exe` from the new releases page and run it over Tracker.

This repository stays so that installed copies of Tracker can still find the update. The Mac version is still called Tracker
and its files are here until it catches up.
